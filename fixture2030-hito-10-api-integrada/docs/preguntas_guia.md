# Síntesis conceptual del Hito 10

La persistencia políglota se demuestra eligiendo una consulta apropiada para cada modelo.
Una API uniforme permite consumirlas sin exponer los clientes de base de datos.
El esquema de respuesta constituye el contrato; la validación se realiza antes de consultar;
la ausencia de datos se diferencia de la indisponibilidad de una dependencia.

No se necesita ampliar el torneo con más casos de uso ni coordinar escrituras para demostrarlo.
La API usa las muestras de los hitos anteriores, agrega seis lecturas y ofrece errores homogéneos.
Las pruebas esenciales verifican éxito, ausencia, entrada inválida, caída y timeout. Los mecanismos
del Hito 11 permiten diagnosticar después en qué capa se encuentra una falla.
